# References and industry data

| File | What it holds |
|---|---|
| [`PAPERS.md`](PAPERS.md) | The research papers QualityRelay builds on, what each supports in this repo, and what it does not let us claim |
| [`references.bib`](references.bib) | BibTeX for every paper and report in `PAPERS.md` |
| [`INDUSTRY_COST_DATA.md`](INDUSTRY_COST_DATA.md) | Cost of one hour of unplanned downtime and of poor quality, with original sources and a confidence level per figure |

Evidence tier for everything in this folder: **external literature and industry surveys**. None
of it is a QualityRelay measurement, and none of it may be promoted to a QualityRelay claim.
